# SmartPay Bulk STK Push Application

A Node.js & Express bulk STK push manager utilizing WebSockets for real-time delivery logs and Bottleneck for API rate limiting (30 requests/minute).

## Setup Instructions

1. Clone repository
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in your `SMARTPAY_API_KEY`
4. Run `npm run dev` for local development
